적용 방법

1. 기존 프로젝트에서 아래 파일을 백업합니다.
   src/App.jsx
   src/styles/unifiedSamsung.css

2. 이 ZIP의 src 폴더를 기존 프로젝트 루트에 복사합니다.

포함 파일:
- src/App.jsx
- src/data/samsungUnifiedData.js
- src/styles/unifiedSamsung.css

3. 실행
   npm run dev -- --force

4. 빌드
   npm run build

데이터 수:
- 삼성 PRO 패턴: 20개 이상
- 삼성 Rich 아카이브: 10개 이상
- CodeTree 삼성 기출/유사 분석: 20개 이상
