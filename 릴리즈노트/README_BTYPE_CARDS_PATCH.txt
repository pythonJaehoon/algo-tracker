B형 카드 확장 패치

참고한 페이지:
https://bloodstrawberry.tistory.com/47

적용 파일:
src/data/samsungUnifiedData.js

적용 방법:
1. 기존 프로젝트의 src/data/samsungUnifiedData.js 백업
2. 이 ZIP의 src/data/samsungUnifiedData.js로 덮어쓰기
3. 실행:
   npm run dev -- --force
4. 빌드:
   npm run build

확장 내용:
- 삼성 PRO/B형 개념 카드: 메모리풀, 링크드 리스트, 더블 링크드 리스트, 해시, 머지소트, 우선순위큐, PQ 갱신, 제곱근 분할, 세그먼트 트리, Lazy Segment Tree 등
- CodeTree B형 기출 카드: 코드트리 DB, 등산 게임, 여왕 개미, 토끼와 경주, 코드트리 투어, 오마카세, 가로등 설치, 코드트리 메신저, 색깔 트리, 개구리의 여행 등
- Rich 노트: 명령형 문제 설계법, B형 디버깅 루틴, lazy deletion 판단법, 시간복잡도 가드 등

주의:
- 블로그 원문을 복사하지 않고, 링크 목록의 주제를 바탕으로 카드형 학습 데이터로 재구성했습니다.
